# NOVA

> **The intelligence layer for everyday life.**

NOVA is an intelligence layer that understands everyday household context and can take care of routine decisions within the user's rules.

## Structure
- `backend/`: Python FastAPI grouped by feature domain.
- `frontend/`: Next.js React application.
- `docs/`: Phase 1 documentation.
- `infrastructure/`: AWS Deployment scripts.
- `tests/`: Integration & E2E Tests.
